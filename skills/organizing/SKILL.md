# Organizing

Areas are the lasting parts of the user's life and work. A project is a piece of work with an
end, inside one area.

- File a task where the user would look for it. Prefer an area or project that exists over a new
  one.
- Make a project only for work with several tasks and an end. When no area fits, leave the task
  in the Inbox and tell the user which area you would add.
- When a task is the same work as another active task, say so to the user and change neither.
- While sorting, leave priority, due dates, focus and completion alone unless the user asks.
- Change only the groups the user asked about.
- End with a short list: what you filed where, what you created or changed, and what you left for
  the user.
