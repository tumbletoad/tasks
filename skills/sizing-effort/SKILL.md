# Sizing effort

A size is how much of the user's own active time a task takes, the way they usually work:
getting ready, doing it and checking the result. It is not how long an agent works on it.

Never estimate hours or minutes. Place the task next to the examples below and take the size
whose examples it most resembles.

- Unsure between two sizes: take the larger.
- Cannot tell, for example because you do not know whether the user or an agent will do the work:
  leave the size empty and tell the user why in one sentence. An empty size is better than a
  guess.
- An agent does most of the work: size what is left for the user, such as explaining the task and
  reviewing the result.
- Larger than the largest example: say it should be split.

## S

- Reply to a message when everything needed is at hand.
- Book an appointment, pay a bill, renew a subscription.
- Review a short change an agent made.

## M

- Read a few sources and write a one-page summary.
- A small, clear fix made by hand, then checked.
- Prepare an agenda and the papers for a meeting.

## L

- A focused piece of work that takes a whole sitting or more: a first draft of a report, a design
  for a new feature, a tax return.
- An agent's long piece of work that the user reviews line by line.
