# CLI verbs

Generated by `pnpm gen` from `packages/contracts`. Do not edit by hand.

These verbs come from the operation registry (A3 3.4.13). The CLI's own commands, such as
`service`, `space` and `doctor`, are documented with the CLI (A2 3.10.1).

Every verb takes `--json` (print the result or the error as one JSON document) and
`--input <file or ->` (read the whole input as JSON from a file or stdin). The CLI fills
`request_id` itself (pass `--request-id` to retry a call), `base` (it reads the task first)
and `cwd`.

Usage: `ttasks add <title> [flags]`

|---|---|---|---|

| `--area` | `tasks[].area` | string | Area name or slug |
| `--project` | `tasks[].project` | string | Project name or slug |
| `--status` | `tasks[].status` | string | A status of the space; default open |
| `--inbox` | `tasks[].inbox` | boolean | Put it in the Inbox for the user |
| `-p`, `--priority` | `tasks[].priority` | integer | 1 highest, 4 none: read skill setting-priority first |
| `--effort` | `tasks[].effort` | string | A size of the space: read skill sizing-effort first |
| `--due` | `tasks[].due` | string | ISO date or phrase: fri, +3d |
| `--waiting-on` | `tasks[].waiting_on` | string | Who or what it waits on |
| `--focus` | `tasks[].focus` | boolean | Star it: on Today until cleared. Only when the user asks |
| `--created` | `tasks[].created` | string | When it was created, only for work that existed before: ISO date or instant |
